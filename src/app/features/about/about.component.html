About

What is CodePrep?

CodePrep is an open, browser-based platform that simulates a real coding interview environment. Candidates practice writing code under time pressure while an AI interviewer asks questions and gives feedback. Interviewers can create sessions, observe candidates live, and take private notes — all from the browser.

Why we built this

Most interview prep tools focus on one thing: solving problems. But real interviews test much more — how you communicate your thought process, how you handle follow-up questions, and how you perform under a time constraint. Practicing on a blank editor with no feedback loop leaves a critical gap.

CodePrep closes that gap. It pairs a professional-grade code editor with an AI interviewer that listens, responds, and challenges your approach — so you can build both your coding skills and your interview skills simultaneously.

For interviewers, CodePrep provides the tools to run real interviews: create sessions with curated problem sets, share a join code with candidates, observe their code in real time, and capture private notes — all without installing anything.

How a typical session works

For Candidates

  1. Browse the problem library — filter by difficulty or search by topic to find a challenge that matches your prep goals.
  2. Open a problem — the page splits into the problem description on the left and the code editor on the right. Pick your language and start coding.
  3. Set the timer — click the timer in the navbar, enter a duration (e.g. 25:00), and press play. The countdown begins.
  4. Toggle interview mode — an AI interviewer panel opens. It asks you to explain your approach, probes edge cases, and follows up on your answers. Speak into your mic or type.
  5. Join a live session — if an interviewer shares a join code, enter it on the Join Session page to start a real interview where the interviewer watches your code live.
  6. Run test cases — execute your solution against the provided test cases, review the output, fix bugs, and iterate until all cases pass.

For Interviewers

  1. Create a session — from the Dashboard, select one or more problems, set a time limit, and generate a unique join code to share with your candidate.
  2. Share the join code — send the code to the candidate via email, Slack, or any channel. They enter it to join the session.
  3. Observe live — once the candidate joins, click "Observe Live" to open a read-only view of their editor. Watch their code, language choice, and progress in real time.
  4. Take private notes — use the built-in notes panel to record observations, flag concerns, or note strengths. Notes are timestamped and auto-saved locally.
